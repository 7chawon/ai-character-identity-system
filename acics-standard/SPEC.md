# ACICS Identity Specification

## 1. Identity Number Structure (ACIN)

Format:
ACIN-YYYY-NNNN-CCCC

- YYYY: Year of initial registration
- NNNN: Sequential issuance number
- CCCC: Character hash checksum (non-reversible)

Example:
ACIN-2025-0001-A9F3

---

## 2. Issuance Principles
- One ACIN per character
- ACIN is permanent and non-transferable
- Re-creation or redesign does not invalidate ACIN

---

## 3. Registration Requirements
- Character name
- Visual or descriptive reference
- Creator declaration
- Initial disclosure date

---

## 4. What ACICS Is NOT
- Not a legal personhood claim
- Not a copyright substitute
- Not a platform-enforced system

ACICS functions as an **identity registry**, not a rights registry.
